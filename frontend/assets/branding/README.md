# CantoBridge 正式 Logo

用户于 2026-10-06 选定候选第 3 款（CB 字母与桥梁），`logo.png` 是其透明 PNG 原图副本。

使用位置：落地页、首次访问入场动画。生成方式及完整提示词见 [候选记录](candidates/README.md)。

动画：柔光背景、logo 上浮与清晰显现、掠光、标语淡入、整体淡出。约 2.65 秒，支持跳过、Escape 和减少动态效果。

首次访问记录：`cantobridge:intro:v1`，独立于账号本地存档；同一浏览器站点首次播放，刷新与退出账号不重播，清除站点数据后重新播放。存储被禁用时仅当前页面会话避免重复。

预览：在网址上加 `?intro=preview`，每次加载都会展示动画，不影响首次访问记录。
