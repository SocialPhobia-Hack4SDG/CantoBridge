# 01 · 产品与用户

## 1. 一句话

CantoBridge 是一个把「粤语学习者」和「粤语母语者」配成一对、用真人实时语音聊天的平台（只做语音通话，不做视频），AI 负责生成贴合两人兴趣的三语话题卡，让不敢开口的人**有话可说、有人可聊**。

## 3. 用户画像

平台只有两种身份，注册时二选一，不可同时拥有。

### 3.1 粤语学习者（Learner）

| 项 | 内容 |
| --- | --- |
| 是谁 | 来港读书的国际学生、非粤语母语的内地学生、来港工作的专业人士、新来港居民，以及对粤语与香港文化感兴趣的人 |
| 现在的状态 | 有词汇、有句型，但一开口就卡；能看懂字幕，听不懂菜市场 |
| 会填的资料 | 母语、粤语水平、学习目标、兴趣标签 |
| 示例档案 | 母语：英语 ／ 粤语水平：初学者 ／ 兴趣：电影、美食、动漫 ／ 学习目标：能够进行日常交流 |
| 他要的结果 | 「我能跟楼下茶餐厅老板点单并且听懂他在说什么」 |

**痛点（按严重度排序）**

1. **没有练习机会。** 找不到愿意花时间、有耐心陪练的本地人；课程和 App 都只到「做题」为止。
2. **不敢开口。** 担心发音不准、怕被纠正、怕尴尬，所以永远停在「我准备好了再说」。
3. **不知道怎么开场。** 就算双方都愿意聊，也没有话题启动器，冷场三秒就结束。
4. **对方不知道该怎么配合。** 本地人不知道该怎么按学习者的水平调整自己的表达。

### 3.2 粤语母语者（Cantonese Buddy）

| 项 | 内容 |
| --- | --- |
| 是谁 | 香港本地学生、职场人士，或单纯想认识不同文化背景朋友、愿意帮人练粤语的人 |
| 关键定位 | **不是「老师」，也不是「义工」。** 产品刻意不使用「教师」角色，也不需要谁单方面付出；语言教学、词汇解释、话题引导这类专业活儿交给 AI 辅助。母语者与学习者是对等的交换双方 |
| 会填的资料 | 兴趣、身份、愿意讨论的话题 |
| 示例标签 | 学生、上班族、动漫爱好者、足球爱好者 |
| 他要的结果 | 一次对等的交换：用几分钟粤语换一次跨文化对话，**可选地**换到自己想练的语言（本轮由「我也想练 X」落地），并拿到可见的认可 |

**痛点**

1. **不知道怎么开始。** 愿意帮忙，但不知道从什么话题切入，也不知道怎么按对方水平调整表达。
2. **付出没有回响。** 只有一句「谢谢」，没有积累也没有回流：帮了几个人、帮了多久都看不见，也没有任何东西流回自己身上。（本轮由**可选回礼「我也想练 X」+ 互补优先排序**回应，见 [07-open-questions.md](07-open-questions.md) 第 9.4 节）
3. **社交压力。** 怕被当成免费劳力或临时老师，也怕对方只索取、不回话。

## 4. 核心场景

### 场景 A · 学习者主动发起（主推，demo 走这条）

刚来港三个月的交换生 A，点「开始粤语练习」进入等待；香港本地学生 B 在匹配页看到 A 的公开信息（母语英语、粤语初学者、兴趣美食/旅行/电影、希望练习「香港日常生活」），判断自己对得上，点进 A 的聊天室。房间从公共匹配页关闭，两人一对一开始聊。AI 生成的话题卡第一张就是「你平时钟意食咩？」——A 卡住了，卡片下方给了「我最近睇紧……」「我最钟意嘅系……」，A 照读并答出来。聊完 12 分钟，双方各拿到正向反馈。

### 场景 B · 母语者被动等待

B 今天有空，切到「我想帮手」，浏览当前正在等待的学习者列表，按兴趣标签挑一个自己聊得来的。等价于场景 A 的镜像视图。

### 场景 C · 冷场救援

Any 一方觉得话题聊完了，直接**滑动话题卡**进入下一张。这是产品的核心交互，直接对应「突然不知道该聊什么」这个最高频的陌生社交尴尬。

### 场景 D · 一次不想暴露身份

A 第一次用，开启匿名模式，只公开「英语母语 / 粤语初学者 / 喜欢电影与美食」，头像与 ID 被屏蔽。降低尝试门槛。

## 5. 价值主张

> **很多人并不是完全不会粤语，而是缺乏真正开口说粤语的机会和勇气。**

把语言学习的顺序从：

**「先学习一门语言，然后再寻找机会使用它」** → **「在真正使用一门语言的过程中学习它」**

支撑这个转变的四个机制：

| 机制 | 解决什么 | 前端要做出什么 |
| --- | --- | --- |
| 一对一 + 实时语音 | 没有练习机会 | 匹配 → 预览 → 通话 → 结算，全链路可演示 |
| AI 三语话题卡 + 可复用句型 | 不知道怎么开口、冷场 | 卡片可滑动、难度随水平变化、带「照抄就能答」的句型 |
| 正反馈（积分、成就、周榜月榜） | 付出没有回响、坚持不下去 | 结束后的结算页 + 成就墙 + 排行榜 |
| **语言交换（母语者可选的「我也想练 X」）** | 母语者只有输出、没有回流 | 资料页一道**可选**题（不填也能过）+ 匹配列表按语言互补优先排序 + 「语言互补」徽标（见 [07-open-questions.md](07-open-questions.md) 第 9.4 节） |

**社会价值（pitch 收尾用）：** 不仅帮用户学粤语，更让来自不同语言与文化背景的人通过粤语认识彼此、了解香港，并逐渐建立对本地社区的**参与感与归属感**。

### 6.2 头脑风暴阶段的竞品扫描（来源：素材 3，**非权威**，仅供 pitch 参考）

早期调研（AI 检索 20~40 个网页）的结论是「没有完全对标的竞品」，并列出以下相邻产品：

| 产品 | 类型 | 与我们的差别 |
| --- | --- | --- |
| 湾趣 | 大湾区青年社交，场景触发（摇一摇记录位置 + 主题地图） | 偏内容分享与兴趣发现，没有「互助 + 认可」机制 |
| UCOO / 泡泡苏打 | 全球华人交友 / 搭子平台，同城与标签匹配 | 本质是兴趣社交，没有跨文化互助与头衔激励 |
| 伴游 / 十六番 | 旅行结伴平台 | 匹配逻辑是行程与目的地，不是「互相帮忙」 |
| 民青局青年内地交流资助计划 | 政府线下交流项目 | 形式是线下项目与资助，不依赖 App 匹配 |

**差异化结论：** 现有产品要么做「兴趣社交」，要么做「官方交流」，没有产品用**轻量的互助 + 认可机制**去解决「两个普通人日常互相帮忙」这个具体场景。竞品空白对我们有利——我们不需要在功能上「打败」谁，只需要论证这个机制缺口。

### 6.3 语言交换型产品（HelloTalk / Tandem / Speaky）

这一节是为 pitch 准备的防线：只要产品触及「互相学对方的语言」，评委一定会拿这几个产品来比。**如果身份模型被改成「能教的语言 + 想学的语言」二合一卡，我们和它们的差别就只剩「我们有话题卡」**（该提议与最终结论见 [07-open-questions.md](07-open-questions.md) 第 9 节）。

| 维度 | 通用语言交换 App | CantoBridge |
| --- | --- | --- |
| 语言广度 | 上百种语言自由配对，默认双方对等互惠 | 只做粤语：一头固定是粤语母语者，不假装两边对等 |
| 配对逻辑 | 「愿意陪练的人」稀缺且随机，冷启动靠用户自己熬 | 粤语母语者的母语本身就是稀缺资产，用**可选回礼 + 互补优先排序**补上回报 |
| 冷场怎么办 | 用户自己找话题 | AI 生成三语话题卡 + 可复用句型，直接对应「不知道怎么开口」 |
| 落点 | 全球泛化、泛兴趣 | 香港本地生活与文化，「对社区的参与感与归属感」（见第 5 节） |

**一句话答法：** 我们不是「随便换一门语言」，而是**用粤语这一个具体入口，解决新来者在香港的实际交流与归属问题**。做成通用语言交换，既打不过成熟产品，也丢掉了唯一的壁垒。
